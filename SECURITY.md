# Security Policy

Il codice sorgente MotoLink è pubblico, ma **secret e credenziali non devono mai essere pubblicati**.

## Non inserire in Issue, commit o Pull Request

- API key private o token;
- `AI_PROVIDER_API_KEY`;
- Supabase chiave server privata key;
- keystore e password di firma Android;
- credenziali personali;
- QR completi o identificativi tecnici sensibili;
- dettagli non corretti di una vulnerabilità che ne facilitino lo sfruttamento.

Per segnalazioni sensibili, usa il **private vulnerability reporting** di GitHub se abilitato oppure contatta privatamente il maintainer.
