# Supporto MotoLink

## Assistente nell'app

Apri **Supporto → Assistente** e descrivi il problema.

Per una domanda normale l'Assistente non legge automaticamente il Log.

Se il problema richiede diagnostica:

1. apri **Supporto → Log**;
2. premi **Condividi**;
3. scegli **Assistente**;
4. MotoLink prepara il Log filtrato e lo allega volontariamente alla richiesta.

## Prima di chiedere assistenza

Indica, quando possibile:

- versione MotoLink;
- modello della moto/display;
- cosa stavi facendo quando è comparso il problema;
- messaggio di errore mostrato nell'app;
- se il problema riguarda connessione, video, profilo, adattamento o Assistente.

Non pubblicare password, API key, token, QR completi o altri secret.
