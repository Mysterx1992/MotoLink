# MotoLink v1.0

Prima release pubblica di MotoLink.

## Download

Allega alla Release l'APK compilato rinominato esattamente:

`MotoLink_V1.0.apk`

Pagina Release ufficiale:

https://github.com/Mysterx1992/MotoLink/releases/latest

Dopo la pubblicazione con tag `v1.0`, il file sarà raggiungibile anche tramite:

https://github.com/Mysterx1992/MotoLink/releases/download/v1.0/MotoLink_V1.0.apk

## Contenuto

- mirroring per display moto compatibili;
- profili moto e Garage;
- app preferite;
- adattamento display;
- modalità tasca;
- Log MotoLink;
- Assistente MotoLink;
- supporto community;
- intro MotoLink Connect.
