# MotoLink V1.1

Aggiornamento di stabilità e usabilità di MotoLink.

## Novità

- Migliorata la stabilità della rotazione durante il mirroring verticale/orizzontale.
- Corretto il pannello Adattamento: compare durante il mirroring in orizzontale, mantiene il tasto × raggiungibile e conserva le regolazioni per profilo.
- Primo START rivisto: HOTSPOT e QR CODE aprono la creazione completa del profilo moto e, dopo il salvataggio, la connessione continua automaticamente.
- Supporto → Log limitato alle ultime 50 righe visibili per alleggerire l'interfaccia.
- Il file `.txt` locale conserva comunque il Log tecnico completo.
- Gli stati generici periodici di video/connessione non vengono ripetuti continuamente nella schermata Log.
- Ripristinata la voce locale “MotoLink Connect” nell'animazione iniziale.
- Varie correzioni di stabilità e usabilità.

## Aggiornamento dalla V1.0

Installare `MotoLink_V1.1.apk` sopra MotoLink V1.0. Non è necessario disinstallare l'app; un normale aggiornamento Android mantiene profili e impostazioni locali.
